# 画像まとめて圧縮(image-compress)

## 概要

複数の画像をまとめて圧縮・形式変換できる、ブラウザ内完結のツール。
画像はサーバーにアップロードせず、Canvas で再エンコードするため、サーバー費用がほぼかからず、利用者にとってもプライバシー面で安心して使える。

## 想定ユーザー

- ブログ・ネットショップ・WordPress サイトの運営者(ページ表示を速くしたい、容量制限に収めたい)
- SNS やフリマアプリに画像を載せる個人(容量削減、位置情報(Exif)の除去)
- Web 制作者・デザイナー(納品前に WebP へ一括変換したい)
- 「画像 圧縮」「jpg 軽くする」「png webp 変換」などで検索してくる一般ユーザー

## MVP の機能

- [x] ドラッグ&ドロップ / ファイル選択で複数画像を追加(JPEG・PNG・WebP・GIF・BMP・AVIF)
- [x] 圧縮品質の設定(JPEG / WebP。PNG 出力時は無効表示)
- [x] 形式変換(元の形式のまま / JPEG / WebP / PNG)
- [x] 長辺の最大サイズ指定によるリサイズ(拡大はしない)
- [x] 1 枚ごとの圧縮前後のサイズ・削減率・解像度の表示、元より大きくなった場合の注意表示
- [x] 1 枚ずつ保存、一括 ZIP ダウンロード(依存なしの自前 ZIP 実装、日本語ファイル名対応、同名ファイルは連番)
- [x] 設定を変えると全画像を自動で再処理
- [x] 広告枠のプレースホルダー、SEO 向けの FAQ

## 構成

- Vite 6 + React 18 + TypeScript(静的サイト。Cloudflare Pages に `dist/` を置くだけで動く想定)
- 圧縮処理: `src/lib/compress.ts`(`Compressor` 型。今は Canvas の `toBlob`、将来 WASM エンコーダに差し替え可能)
- ZIP 生成: `src/lib/zip.ts`(無圧縮 STORE 方式。画像は既に圧縮済みのため Deflate は不要と判断)
- 計算・命名: `src/lib/format.ts`

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド
npm test          # ZIP・サイズ計算のテスト(Node 22.6+ の型ストリップを使用)
```

## 収益化案

1. **ディスプレイ広告**(AdSense 等): 処理待ち・結果表示の近くに 1〜2 枠。ツール系は滞在時間が短いので、結果一覧の下に置き邪魔にならない配置にする
2. **SEO 流入の最大化**: 「jpg 圧縮」「png webp 変換」「画像 一括 リサイズ」など用途別のランディングページを作り、同じツールを初期設定違いで見せる
3. 将来案: 枚数無制限・高圧縮エンコーダ(MozJPEG / AVIF)・フォルダ構造維持などの有料版(買い切り or 月額少額)、ブログ向けアフィリエイト(レンタルサーバー・WordPress テーマ)

## 集客案

- 用途別ページ(「Instagram 用にリサイズ」「メルカリ用に軽くする」「WordPress 用に WebP 変換」)で検索キーワードを広く取る
- 「アップロードしないので安全」を前面に出し、社内資料・個人写真を扱う人に訴求
- 開発者・ブロガー向けに Zenn / Qiita / note で「ブラウザだけで画像圧縮を作った」記事を書く
- 既存サービス(S02 シフト画像、S05 OGP ジェネレーター)からの相互リンク
- PWA 化してホーム画面に追加できるようにし、リピート利用を増やす
